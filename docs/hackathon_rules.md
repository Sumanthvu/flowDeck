## ⚙️ Hacking Rules
* **Red Light**: Laptops must be closed or paused. Screen mirroring to the laptop is allowed passively via Office Kit, but active typing or mouse input from the laptop is prohibited. You must type on a keyboard connected directly to the phone.
* **Green Light**: Free laptop and phone usage. Ideal for running native compilations (`run-android`), library additions (`npm install`), and syncing git commits.
* **Office Kit**: Keeps phone mirrored. Must be kept active (scoring increases with phone-bridge connection duration).

## 📊 Scoring Rubrics (100% Total)
1. **iQOO Office Kit Usage (25%)**: Scored via HackTracker at Judging Round 2 (Sun 12:00).
2. **Phone-First Execution (25%)**: Runs on the iQOO phone with a native feel, offline capability, and NPU acceleration.
3. **AI-Native Build (20%)**: Prompting efficiency, model optimization (1B-2B params, quantization), and token stream latency.
4. **Problem Fit & Real-World Use (20%)**: How well it solves Indian students' JEE/NEET/UPSC prep needs.
5. **Craft & Pitch (10%)**: UI/UX polish and defending tradeoffs during live demos.
